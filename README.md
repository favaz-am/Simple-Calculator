# 🧮 Simple Calculator

A lightweight calculator built with **HTML, CSS, and JavaScript**. This beginner-friendly project provides a simple interface for performing basic arithmetic calculations.

## ✨ Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Interactive number and operator buttons
- Calculator display for entering and viewing expressions
- Clear button to reset the display
- Custom mathematical background
- No frameworks or external libraries required

## 🛠️ Tech Stack

- **HTML5** — Calculator structure
- **CSS3** — Styling, layout, and visual design
- **JavaScript** — Button interactions and calculation logic

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/favaz-am/Simple-Calculator.git
   ```

2. Open the project folder:

   ```bash
   cd Simple-Calculator
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No package installation or build process is required.
